# PhishGuard - URL Phishing Detector

PhishGuard is a browser-based phishing URL detector that analyzes URLs for common phishing indicators.

Features:
- Detects HTTP URLs
- Detects IP address URLs
- Detects suspicious keywords
- Detects typosquatting attempts
- Detects URL shorteners
- Detects dangerous file extensions
- Calculates a phishing risk score
- Displays warning flags with severity levels

Technologies Used:
- HTML5
- CSS3
- JavaScript

 How It Works:
The application uses rule-based analysis to identify phishing characteristics and assigns a risk score based on detected threats.
